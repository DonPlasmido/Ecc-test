# Epic: Lista de movimientos

**Slug:** transaction-list
**Status:** ready
**Created:** 2026-11-17

## Goal

Que el usuario busque, filtre y edite movimientos con fluidez incluso con 100.000 movimientos almacenados, con umbrales de rendimiento medidos por benchmark.

Funcionalidad F5 de `docs/BRIEF.md`. Criterios: `docs/acceptance-criteria.md` (sección F5).

## Scope

- Lista virtualizada
- Búsqueda y filtros combinables
- Edición de categoría, concepto visible y nota
- Benchmark automatizado de filtrado

## Out of Scope

- Edición masiva
- Exportación a CSV
