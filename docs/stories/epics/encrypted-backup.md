# Epic: Copia de seguridad cifrada

**Slug:** encrypted-backup
**Status:** ready
**Created:** 2026-11-17

## Goal

Que el usuario exporte e importe todos sus datos en un archivo cifrado con contraseña usando solo WebCrypto, sin que un archivo dañado o una contraseña errónea alteren sus datos.

Funcionalidad F6 de `docs/BRIEF.md`. Criterios: `docs/acceptance-criteria.md` (sección F6).

## Scope

- Exportación cifrada (PBKDF2-SHA-256 + AES-GCM-256)
- Restauración con confirmación y atomicidad
- Rechazo de contraseña incorrecta, archivo manipulado o versión incompatible

## Out of Scope

- Sincronización en la nube
- Recuperación de contraseña olvidada
- Copias automáticas programadas
